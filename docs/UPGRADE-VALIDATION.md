# Cloudflare 与桌上互动：验证记录

日期：2026-10-15，马来西亚时间。目标仓库 `Tzy0701/NasiLemak`，分支 `claude/nasi-lemak-online-game-k1qte5`。

## 已实现

- 根据用户选择，默认恢复 Cloudflare Workers Static Assets + SQLite Durable Objects；移除 Render 部署配置，不需要 D1。保留原 Worker 名、房间绑定、类名和迁移，已有新增功能全部保留。
- 私有座位投影、幂等确认保存、单计时器、全体真人离线暂停、到期清理与重连恢复。正常休眠唤醒不重写状态或重排定时器，浏览器心跳由 Hibernation 自动回复。
- 12 款透明背景插画贴纸与 12 条中英文固定短句，可定向发送、投掷展示、静音；不消耗行动、不写入游戏状态或永久聊天记录。限流及最近确认存入连接附件，跨休眠和同一玩家多个页面继续有效。
- 小偷逐位手动点选匿名背面牌，每位有效对手各一张，一张小偷只扣一次行动；带私密翻牌提示和飞牌效果，支持刷新、超时、机器人和离开场景。
- 手牌分类／数量／名称排序并保存偏好，二维码邀请、继续上局前检查、交易一览与缺牌提示、本桌累计战绩、公开最近动作和动画回看。
